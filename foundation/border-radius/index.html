Border Radius

Corner radius on the same 4-point steps as spacing. Each token is read live from tokens/dm_tokens.css (--number-border-radius-N); use the short alias var(--border-radius-N) from styles/scss/foundation/_border-radius.scss. The name is the value in px. Figma: variables number/border-radius/….

Scale

Everyday steps: 0 · 4 · 8 · 16 and Full. The rest (shown lighter) are rarely used — reach for an everyday step first. Nested corners: inner radius = outer radius − the padding between them (a card with --border-radius-16 and 12px padding holds a --border-radius-4 button).
