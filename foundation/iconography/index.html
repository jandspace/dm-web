Iconography

Every icon in the DM icon library, loaded from assets/icons/ — SVG files exported from the Figma library (DailyMail Icons › Icon, 24:2253) with visible layers only, grouped as in Figma. Click an icon to copy its path.

Rules

  • Web uses SVG only — no icon fonts, no PNG. Load the file from assets/icons/; never redraw an icon or re-export it into a page.
  • One grid: every icon is drawn on 32 × 32 and scales down (24, 20, 16). Keep it square.
  • Colour: icons are single colour (black). When an icon must follow a colour or a state (hover, theme), inline its path as an SVG <symbol> with fill="currentColor" and set the colour with a color/icon/* token. -color channel icons and flags keep their own colours.
  • Names: ico-{name} plus a style suffix — -outline, -circle, -square, -color. Channels are ico-ch-*, social ico-sn-*, flags ico-flag-*.
  • Accessibility: a decorative icon gets alt="" or aria-hidden="true"; an icon-only button carries its label (aria-label).
