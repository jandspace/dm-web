Spacing

A 4-point scale for padding, margin and gap. Each token is read live from tokens/dm_tokens.css (--number-spacing-N); use the short alias var(--spacing-N) from styles/scss/foundation/_spacing.scss. The name is the value in px. Figma: Web UI Kit › Spacing (page 214:6479), variables number/spacing/….

Scale

Sub-atomic steps (1 · 2 · 6 · 10, shown lighter) are for precision only — when in doubt, take the next 4-point step. Never use a value outside the scale.

Layout spacing

Columns carry no padding — every card or block holds its own 16px inset (--spacing-16), so neighbours sit 32px apart. See Layout & Grid and docs/3_Foundation__04_Spacing.md.
