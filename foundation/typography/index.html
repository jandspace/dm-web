Heading tags

The tag sets the page outline, the class sets the size — never pick a tag for its size. h1: one per page (page title). h2: section headers and modal titles. h3: every article headline in a card, whatever its size class (e.g. <h3 class="h5 article-headline">), including cards above the first section header. No SEO cost: heading level is not a ranking signal. The gain is accessibility — screen-reader users jump between sections (h2) and articles (h3).

Line height · weight

Line height is a unitless multiplier — never px on Web. No letter spacing: every style uses the browser default (the font's own spacing).
