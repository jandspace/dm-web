Input

Form fields — Input, Select and Textarea share one box, three sizes (Button heights 34 · 40 · 46), two shapes and one set of states. Colours follow the semantic rules: focus semantic-info, valid semantic-success, error semantic-error. Figma: Web UI Kit › Input (210:6470). Doc: docs/4_Components__13_Input.md.

Input — sizes, shapes and states

Figma order: SM · MD · LG, Rectangle then Pill. Focus, Valid and Error draw a 2px border (1px border + 1px inset ring), so nothing moves. Error is the only state with a tinted background. Focus is shown here with .is-focus.

Select

Native when the options are text only; Dropdown (Dropdown Menu) when they need an icon or more. A native <select> has no read-only mode — a read-only choice uses the Dropdown Select with aria-readonly="true".
