Tabs

A row of options, one selected — as a filter (switches what shows below) or as navigation (links to pages). Two looks: Underline and Button. Selected in neutral/darker; Button tabs take the channel's base colour inside a channel. Figma: Web UI Kit › Tabs (1488:57719). Doc: docs/4_Components__09_Tabs.md.

Button

label-sm Semibold pills, 4px apart; selected: neutral/darker fill. Inside a channel the selected fill takes the channel's base colour (.tabs--sport …) — Button only. Keyline under the row (border/translucent-dark/pale) — optional, .tabs--no-keyline. 2–3 tabs can share the full width: .tabs--fill.
