Pagination

Moves between the pages of a long list. Two patterns: numbered from LG (scan and jump), a page picker below LG (‹ [ 2 ] of 999 › — the phone's own picker, big touch targets). Figma: Web UI Kit › Pagination (214:7642). Doc: docs/4_Components__07_Pagination.md.

Try it

Click a page or an arrow, or pick a page below LG. Resize the window to switch pattern at LG (1024).

Numbered — LG ≥1024

Always 7 number slots: first and last, the current page with its neighbours, an ellipsis where pages are skipped. ‹ › only where there is a page to go to; « » only when they go further than ‹ ›.

Page picker — MD and SM-XS <1024

A native <select> in the Input look — on phones it opens the system picker. 44px arrows.

Items

Figma "pagination-item". Hover follows Button: background only, no shadow. The ellipsis is not a link.
