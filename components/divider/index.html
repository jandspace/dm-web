Divider (Keyline)

A 1px color/effect/translucent-dark/pale line between content blocks, horizontal or vertical, with or without a 16px inset at both ends. Each block draws its own keyline as a pseudo-element with the divider mixin, and the last block has none. Grey boxes stand in for cards. Figma: Web UI Kit › Divider (Keyline) (92:860).
